# 限定棋盘抽卡模拟器

**版本**: V0.2.1（保护性措施增强版）
**最后更新**: 2026-05-31
**开发语言**: Python 3.12+
**GUI框架**: Tkinter (ttk主题)

---

## 项目简介

本软件为**异环游戏**的第三方抽卡模拟工具，用于学习和研究概率系统。

支持多棋盘切换、完整的保底机制、分支系统、十连抽等核心功能。

---

## 核心特性

### 游戏机制
- 方形顺时针蛇形棋盘布局（54格主路径 + 2个9格分支）
- 完整概率暗箱系统（S级1.87%、A级角色11.67%等）
- S级保底系统（70抽变格、90抽硬保底）
- 集点赠礼机制（每10次触发）
- 分支系统（S级角色区 + 皮肤惊喜区）

### 多棋盘支持
- **限定棋盘（浔）**: limited_xun
- **限定棋盘（安魂曲）**: limited_requiem
- 动态棋盘架构：模板+覆盖设计模式
- 运行时动态切换棋盘

### 保护性措施（V0.2.1新增）
- 抽卡按钮锁定机制（防止重复点击）
- 操作保护系统（重置/切换棋盘时智能检测）
- 发布版本日志禁用（DEBUG_MODE=False）
- 弧光盲盒异常修复（计数器不再丢失）

### 其他功能
- 5档速度控制系统（0.5x/1x/2x/4x/跳过）
- 单次投掷 + 十连投掷
- 骰子消耗系统（红骰 + 环石）
- 皮肤装扮礼遇系统
- 自适应窗口布局

## 快速开始

### 1. 安装Python
确保已安装Python 3.12+，并添加到系统PATH。

### 2. 运行程序
```bash
cd 抽卡模拟器
python main.py
```

### 3. 使用说明
1. **选择棋盘**：使用右上角下拉框选择限定棋盘（浔或安魂曲）
2. **调整设置**：配置骰子数量、速度等参数
3. **开始抽卡**：点击"? 1 抽"或"? 10 抽"按钮
4. **查看结果**：观察奖励弹窗和日志区域

## 技术架构

### 核心模块
| 模块 | 职责 | 代码行数（约）|
|------|------|-------------|
| main.py | UI构建、事件处理、动画控制 | 3600+ 行 |
| game_logic.py | 游戏状态机、概率计算、奖励生成 | 1600+ 行 |
| board_data.py | 数据配置、模板定义、动态接口 | 1800+ 行 |

### 设计模式
- **MVC架构**：Model(game_logic) - View(main.py UI) - Controller(事件处理)
- **模板方法模式**：LIMITED_BOARD_TEMPLATE + BOARD_REGISTRY
- **状态机模式**：GameState管理保底、赠礼等状态
- **策略模式**：不同格子类型的解析策略

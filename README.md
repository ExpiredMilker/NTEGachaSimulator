# Gacha Simulator V1.0.0

抽卡模拟器 - 基于棋盘走格子的抽卡游戏模拟工具
该项目包含AI辅助开发部分

## 版本信息

- **版本号**: V1.0.0
- **发布日期**: 2026-07-05
- **Python版本**: 3.12+
- **依赖**: tkinter (Python标准库)

## 功能特性

### 核心玩法
- 棋盘式抽卡：通过掷骰子在棋盘上移动，到达不同格子触发不同奖励
- 五种棋盘模式：
  - **限定棋盘-浔**（红骰）：限定角色池，含变格机制
  - **限定棋盘-安魂曲**（红骰）：限定角色池变体
  - **限定棋盘-卡厄斯**（红骰）：限定角色池，含变格机制
  - **限定棋盘-真红**（红骰）：最新限定角色池
  - **常驻棋盘**（蓝骰）：常驻角色池

### 抽卡系统
- 单抽 / 十连抽
- 保底机制：
  - 软保底：70抽后进入"变格状态"，棋盘格子发生变化
  - 硬保底：垫刀89次后，第90次投掷不移动直接获得S级角色
- 骰子系统：蓝骰 / 红骰 + 环石消耗
- 充值系统：模拟人民币购买环石

### 变格系统
- 垫刀数 >= 70 时自动进入变格状态
- 部分格子类型发生变化（如勇者宝箱 -> 同行S级角色）
- 可视化棋盘同步显示变格效果
- 获得S级角色或硬保底后恢复基准棋盘

### 分支路径
- 棋盘含分支路径（B1分支、B2分支）
- 支持从主路径进入分支、在分支内移动、离开分支返回主路径
- B1分支为S级角色区，B2分支为皮肤惊喜区

### 宝箱系统
- 学徒宝箱：S级概率0.2%，其余为B级
- 勇者宝箱：S级概率3%，其余为B级
- 变格后宝箱类型变化：
  - 学徒宝箱变 -> 勇者宝箱
  - 勇者宝箱变 -> 必定获得同行S级角色(100%)

## 运行方式

需要Python 3.12+环境（tkinter通常是Python自带的）：

```bash
python main.py
```

## 操作说明

1. **选择棋盘**：顶部标签页切换浔/安魂曲/卡厄斯/真红/常驻
2. **设置起点**：可自定义起始位置（默认0号格子）
3. **设置骰子数量**：输入蓝骰/红骰数量和环石
4. **开始抽卡**：点击"单次投掷"或"十连投掷"
5. **查看结果**：弹窗显示获得的奖励

## 注意事项

- 仅支持Windows系统（7/8/10/11 64位）
- 本版本所有棋盘数据已硬编码到Python文件中，无需额外CSV/TXT数据文件即可运行
- 可进一步使用PyInstaller打包为单文件exe

# 限定棋盘抽卡模拟器 (Gacha Simulator)

**版本**: V0.1.2  
**更新日期**: 2026-05-28  
**作者**: 过期牛奶

## 项目简介

这是一个基于Python Tkinter开发的限定棋盘抽卡模拟器，完整实现了游戏中的走棋系统、概率暗箱机制、分支系统等核心功能。

### 核心特性

- **方形顺时针蛇形棋盘**: 54格主路径 + 2个9格分支（S级角色区 + 皮肤惊喜区）
- **完整的概率系统**: 严格遵循官方规则，包含S级保底、变格、集点赠礼机制
- **两段式移动算法**: 分支离开时精确控制移动路径
- **多档速度控制**: 支持0.5x/1x/2x/4x/跳过5种速度模式
- **单次投掷 + 十连投掷**: 模拟真实游戏体验
- **骰子消耗系统**: 红骰 + 环石双货币机制
- **皮肤装扮礼遇系统**: 支持时装、涂装、滑翔翼3种皮肤类型

## 游戏功能说明

### 走棋规则

#### 主路径（0-54号）
- **起点(0号)**: 第一次抽卡的起始位置，不参与循环
- **循环范围**: 1-54号（共54格）
- **循环终点(54号)**: 到达后再掷骰子从1号继续

#### 分支系统

**分支1 - S级角色区（16号入口）**
- 入口: 16号格子
- 路径: B1-0 → B1-8（9格）
- 出口: 18号格子
- 特殊: B1-0为S级角色格子

**分支2 - 皮肤惊喜区（43号入口）**
- 入口: 43号格子
- 路径: B2-0 → B2-8（9格）
- 出口: 45号格子
- 特殊: 包含多种皮肤类型格子

#### 分支触发规则
- 到达分支入口时：可选择进入分支或跳过
- 选择进入：从B1-0/B2-0开始走分支路径
- 选择跳过：直接到达跳过点（17号/44号）

#### 分支离开算法（两段式移动）

当在分支末尾投掷的点数超出分支范围时：
1. **段1**: 在分支内走到末尾位置
2. **跳转**: 从分支末尾跳转到对应出口
3. **段2**: 在主路径上继续移动剩余步数

**示例**: 在B1-8(63号)投6点
- 段1: 已在末尾，0步
- 跳转: 63 → 18（出口）
- 段2: 从18开始走5步 → 最终到达23号
- 总计: 0+1+5 = 6步 ✅

### 概率系统

#### S级角色获取
- 基础概率: 1.87%（浔当期限定）
- **70抽变格**: 勇者宝箱S级概率提升至60%
- **90抽硬保底**: 必出S级角色
- 集点赠礼: 每10次触发一次额外抽取机会

#### 皮肤系统
| 类型 | 触发概率 | 首次获得率 | 领取阈值 |
|------|---------|-----------|---------|
| 今日穿搭（时装）| 0.33% | 0.68% | 200次 |
| 改装时刻·涂装 | 0.33% | 1.00% | 120次 |
| 风向标（滑翔翼）| 1.71% | 2.96% | 50次 |

### 操作说明

- **单次投掷**: 点击"投掷"按钮进行一次随机投掷
- **十连投掷**: 点击"十连抽"按钮连续投掷10次
- **重置游戏**: 清除所有进度重新开始
- **速度调节**: 使用滑块调整动画速度（0.5x-4x或跳过）

## 技术亮点

### V0.1.2核心修复

#### 致命Bug修复: is_already_in_branch未赋值 ⭐⭐⭐

**问题**: 分支内移动时关键变量未正确赋值，导致：
- 分支1结束错误进入分支2（而非出口18）
- 所有分支离开操作异常

**修复**: 在分支状态检测时添加缺失的赋值语句
```python
elif in_branch or self.engine.in_branch:
    is_already_in_branch = True  # 关键修复
    if self.engine.in_branch:
        target_branch_key = self.engine.in_branch
```

#### 其他重要修复
- ✅ `steps_to_exit`计算公式修正（去掉多余的+1）
- ✅ 分支入口跳格问题修复（补偿-1步）
- ✅ done()回调函数不再覆盖正确的棋子位置
- ✅ 测试骰子功能已注释（正式版使用随机投掷）
